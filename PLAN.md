# EngineerPro Rebuild — Plan

A static-site rebuild of [engineerprogurus.com](https://engineerprogurus.com/), deployable to **GitHub Pages** from the `docs/` folder.

---

## 1. Tech stack

- **Pure static**: HTML5 + modern CSS (custom, no framework) + a tiny vanilla JS for tab switching / mobile nav.
- **No build step required** for the site itself — `make github` simply syncs `src/` → `docs/` so GitHub Pages can serve it.
- **Local preview** via `python3 -m http.server 8001` inside `docs/`.

Why no framework? The user wants quick GitHub Pages deployment, and the content is mostly static. A vanilla site is easiest to host, cheapest to maintain, and the brief is small.

---

## 2. Site map (single-page app with hash routing)

A one-page site with a sticky top nav. Clicking a tab swaps the visible section using `#hash` routing — keeps GH Pages happy (no server rewrites needed).

| Podcast | `#podcast` | Episodes from `engineerprovn.substack.com/podcast/archive` |
| Hình thức học | `#format` | Zoom live + Discord support |
| Liên hệ | `#contact` | Placeholder — info TBD |

## 4. Visual design

- **Palette**: dark navy `#0b1d3a` + EngineerPro orange `#ff7a18` + soft cream `#f8f5ef`.
- **Typography**: Inter (system fallback) for body, Space Grotesk for headings.
- **Layout**: 1200px max-width container, CSS Grid for card sections, sticky nav with backdrop blur.
- **Components**:
  - Hero with gradient + CTA buttons.
  - Stat strip (dynamic from data: 20 mentors, 12 courses, 19 podcasts, 113 stories).
  - Card grid (3 columns ≥ 1024px, 2 columns ≥ 640px, 1 column mobile).
  - Mentor avatar cards with initial-based color blocks (no external images needed).
  - Footer with social placeholders.
- **Responsive**: mobile-first; hamburger menu under 768px.

---

## 6. Makefile contract

```make
make github   # rsync src/ → docs/ (creates docs/.nojekyll)
make serve    # python3 -m http.server 8001 -d docs
make clean    # rm -rf docs
```

`make github` is what the user runs before pushing to GitHub. GH Pages → Settings → Pages → branch `main`, folder `/docs`.

## 7. Out of scope (for this pass)

- No CMS / no backend.
- No real user authentication / payments.
- No real images of mentors (we render initials in coloured tiles instead — easy to swap in real photos later).
- Contact info intentionally left blank; user will provide.
