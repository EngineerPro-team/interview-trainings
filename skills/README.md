# Skills

Project-specific how-to docs for the EngineerPro static site.
Each `<skill>/SKILL.md` is a self-contained recipe for one kind of update,
written so a future agent session (or a returning maintainer) can finish
the task with minimal back-and-forth.

| Skill | Use when |
|---|---|
| [site-overview](site-overview/SKILL.md) | Anything unfamiliar — read first |
| [add-mentor](add-mentor/SKILL.md) | User sends a mentor photo + LinkedIn / role |
| [add-company-logo](add-company-logo/SKILL.md) | User sends a company logo image |
| [update-content-counts](update-content-counts/SKILL.md) | Stats / counts need updating |
| [deploy-and-preview](deploy-and-preview/SKILL.md) | "Push lên", "preview local", deploy/build questions |
| [content-pipeline](content-pipeline/SKILL.md) | Refresh stories / courses / podcast / FAQ |

These are READMEs, not magic. They follow the Cursor SKILL.md format
(YAML frontmatter + concise body) so they can also be loaded as agent
skills if you copy them under `.cursor/skills/` later — currently they're
just easy-reference docs for humans.
