## Commands

```bash
make github     # build docs/ from src/
make serve      # serve docs/ at http://localhost:8001
make dev        # github + serve in one shot
make clean      # remove docs/
```

## Deploy to GitHub Pages

1. `make github` (builds `docs/`)
2. Commit & push `docs/`
3. In your GitHub repo: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, Folder: `/docs`**

The build script writes a `.nojekyll` file so GitHub Pages does not try to process the site with Jekyll.

## Tech

Pure HTML + CSS + vanilla JS. No build tools required.
